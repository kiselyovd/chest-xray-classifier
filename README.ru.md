# Классификация рентгенограмм грудной клетки

[Интерактивная витрина](https://kiselyovd.github.io/chest-xray-classifier/showcase/) · [Полный README / English](README.md) · [Модель](https://huggingface.co/kiselyovd/chest-xray-classifier)

ConvNeXt-V2-Tiny классифицирует педиатрические снимки как норму, бактериальную или вирусную пневмонию. Оригинальный test-набор из 624 изображений скачан и зафиксирован хешами. Повторный запуск опубликованных весов воспроизвёл всю матрицу ошибок и исходные метрики; актуальную таблицу CI генерирует из [artifact manifest](artifact-manifest.json) в [английском README](README.md#current-artifact-and-evaluation).

[Контракт и повторение оценки](docs/EVALUATION.md) · [Результаты по каждому изображению](reports/replay-native-2026-10-15.json). Сохранены вероятности и целевые метки, порядок классов и идентификаторы модели/данных/кода.

Исправлен native processor: shortest-edge resize 255 bilinear, crop 224 с тем же округлением, что в torchvision, и ImageNet-нормализация. На всём test-наборе native-путь и обработка входа из репозитория дали одинаковые классы и AUROC. Прямой пример torchvision + safetensors в README закреплён на конкретной ревизии.

Baseline DINOv2 остаётся сохранённым отчётом: соответствующих весов нет в текущем Hub snapshot. Исторический состав training-набора и независимость пациентов не подтверждаются старой записью запуска. Это исследовательский артефакт без клинической валидации.
